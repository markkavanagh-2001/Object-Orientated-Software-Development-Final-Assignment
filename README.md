This repository contains the code  that was written for the Object Orientated Software Development module final assignment.

The repository contains a src folder which contains the source code and a ReadMe.pdf file that contains the instructions on how to run the program and any unique feature of the code.
It also contains hdipSwOOAssignment2025-26.pdf which is the assignment brief that was to be followed.

The project involved developing a Java application that was capable of encrypting and decrypting a text file using a four square cipher. The details on how to run the program are included in the ReadMe.pdf file.
